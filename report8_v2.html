2. アノマリー ―― 理論・軸・形式系の修正を導くもの

判定の基準：形式系が「通る」と判定したのに買い手が落とし、かつ原因が 述語の欠落・型の誤り・定義域の不足にあるもの。生成器が仕様を読み違えただけのものは含めない。

修正　推論規則 (6) に expressible(P, κ_n) を追加する。⑥は κ_n の基準で読める量（回収年数・粗利の変動・手元資金の増減）を必ず含む。

A6R10b と A1 が両立しない 2/8（明示）形式系

K2-P1 の生成器は R10b（②で数え直した単位を⑥で比例換算して戻すな）を守り、「円／人日へは割り戻しません」と書いた。買い手（κ_n＝価格）はその一行で終わらせた——「割り戻せないものは、うちでは値段が付かん」。規則を守ると中心命題を破る。生成器は自己申告で「換算禁止の射程（併記も禁止か）が判断できなかった」と書いている。

A7消去次元が座席構造と無関係に立つ 3/8軸（D軸）

F2（オーナー系中堅、親会社なし）の2セルで、買い手の第一声が「うちに親会社はないよ」だった。K1-P2 では「当社が元請だ。承認するのはこちら側であって、こちらが承認を待つ側ではない」。ALLOWED 表は 手段の類型 × 次元 しか見ておらず、その拘束者が買い手の外側の上位に実在するかを見ていない。D6c は向きを持つ関係なのに、δ は向きのない集合を返している。

A8④の日付が「この買い手に効く日か」を検査していない 3/8軸（T軸）

F2-P2「四月一日の線も、六年前に越えてる」。K1-P2「建設に適用されたのは2027年ではなく2024年4月1日だ」。K2-P1「どの元請の話だ。うちは元請が複数あって、審査の窓もばらばらだ」。外部性の3条件（制御不能・撤回不能・未計算の量）も出典階層も既知度も全部通したうえで、その日付が当該買い手に適用されるかだけが検査されていない。出典階層は「誰が決めた日か」を見るが「誰に効く日か」を見ていない。

修正　T軸の必須フィールドに 適用対象（業種・規模・区分・当事者の同定）を追加し、applies(d, buyer) を now(Q) の連言に入れる。拘束者が複数いる場合（元請が複数）は、日付が一意に定まらないので、当事者を同定するまで④は立たない。

A9③で名づけた対象と⑥が消す対象の同一性が検査されていない 3/8形式系

F1-P1 が最も鋭い——「この装置が消すのは盛付や持ち替えといった定常作業であって、②で数えた『立ち上がりが安定するまでの上乗せ』の中身は品質確認・手直し・ライン調整・洗浄立ち上げだ。数えた人日と装置が置き換える人日が同じ集合だという説明がどこにもない」。R10 は単位と周期を検査するが外延を検査しない。推論規則 (6) は P ∈ C と無矛盾性しか要求せず、resolve の Q が③の Q と同じ集合を指すことは仮定されているだけである。
